پروژه درس سوم آمادگی دفاعی نهم - روایت فتح

اجرا:
1) فایل ZIP را از حالت فشرده خارج کنید.
2) پوشه defaei-lesson3 را در VS Code باز کنید.
3) فایل index.html را در مرورگر اجرا کنید (یا با افزونه Live Server باز کنید).

فایل‌ها جدا هستند:
- index.html : ساختار صفحه
- style.css : ظاهر و واکنش‌گرایی
- script.js : منو، کارت‌های تعاملی، گالری و آزمون

تصاویر از Unsplash بارگذاری می‌شوند؛ برای نمایش آن‌ها اینترنت لازم است.
عنوان و محتوای درس بر اساس عنوان درس سوم در نسخه جدید کتاب (روایت فتح) تنظیم شده است.
